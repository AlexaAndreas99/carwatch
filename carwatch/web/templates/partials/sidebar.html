{# The configuration sidebar (configurations plan §5). Replaces the two toolbar dropdowns that used to disagree with each other — Listings picked a configuration by name, Changes picked a configuration *and* a site. One selection now, shared by both pages and carried in the URL. Selecting an entry does one of two things, depending on the page. On Listings and Changes it *scopes in place*: `keep` rebuilds the current URL with a different `config`, so you keep the market tab, the filters and the sort you already had. Everywhere else — a configuration's own page, its form, one of its sources — there is nothing to scope, so selecting *navigates* to that configuration. A page opts into that with `{% raw %}{% set sidebar_navigates = true %}{% endraw %}`. Without it those pages would build links like `/search/7?config=juke`, which keeps you exactly where you were. #} {% set navigates = sidebar_navigates | default(false) %} {% macro keep(slug) -%} {%- if navigates -%} {{- ('/config/' ~ slug) if slug else '/' -}} {{- '?disabled=1' if (slug and sidebar.show_disabled) -}} {%- else -%} {{- keep_scope(slug) -}} {%- endif -%} {%- endmacro %} {% macro keep_scope(slug) -%} {%- set pairs = [] -%} {%- for key, value in request.query_params.multi_items() -%} {%- if key not in ('config', 'disabled') -%} {%- set _ = pairs.append(key ~ '=' ~ (value | urlencode)) -%} {%- endif -%} {%- endfor -%} {%- if slug %}{% set _ = pairs.append('config=' ~ slug) %}{% endif -%} {%- if sidebar.show_disabled %}{% set _ = pairs.append('disabled=1') %}{% endif -%} {{ request.url.path }}{% if pairs %}?{{ pairs | join('&') }}{% endif %} {%- endmacro %} {% macro toggle_disabled() -%} {%- set pairs = [] -%} {%- for key, value in request.query_params.multi_items() -%} {%- if key != 'disabled' -%} {%- set _ = pairs.append(key ~ '=' ~ (value | urlencode)) -%} {%- endif -%} {%- endfor -%} {%- if not sidebar.show_disabled %}{% set _ = pairs.append('disabled=1') %}{% endif -%} {{ request.url.path }}{% if pairs %}?{{ pairs | join('&') }}{% endif %} {%- endmacro %}
